# 問題集の写真の置き場所（このフォルダの中身は Git に入らない）

成山堂・海文堂の紙面写真は出版社の著作物。このリポジトリは **公開（public）** なので、写真はここにコミットしない。

推奨: Google Drive に次のフォルダを作って写真を入れる（Claude は接続済みの Google Drive から画像を直接読める）。

```
海技英語_問題集写真/
  成山堂/   例: 成山堂_2026-04_問1.jpg
  海文堂/   例: 海文堂_2025-10_問2.jpg
```

ファイル名に「出版社_年-月_問番号」を入れておくと照合が速い。分からなければ連番でもよい。
