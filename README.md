## 現時点で分かっていること（出題表ベース）

- 1期2題。2023/02〜2026/02 の全13期が「再出題1題＋新規1題」。
- 同一英文の再出題間隔は **中央値5.00年**（42件）。2011年以前の注記との間隔も中央値5.00年（19件）。
- 再出題の元は古い順に進んでおり、2026/02 時点で 2020/07 出題分まで来ている。次は 2020/10〜2021年頃の英文が再出題候補（**仮説**。2026/04・07 の実データで要確認）。
- テーマ別の出現回数上位: 航海計画・航路指定・水路（13）、航海当直・船橋業務（11）、救命設備・非常配置（11）、気象・海象（9）。

## 続けるために必要なもの

1. 成山堂・海文堂の写真を Google Drive の `海技英語_問題集写真/成山堂/`・`/海文堂/` に入れる（`data/raw_photos/README.md`）。**このリポジトリは公開なので写真はコミットしない。**
2. 作業環境のネットワーク設定で `www.mlit.go.jp`・`wwwtb.mlit.go.jp` を許可する（国交省原本の照合用）。
