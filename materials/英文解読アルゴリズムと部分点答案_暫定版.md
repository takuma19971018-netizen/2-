## 1. 先に知っておくべき事実（出題表から）

- 二級航海の英語は、出題表では **1期2題**（2014年以降はほぼ一貫）。
- 2023/02 以降は **「約5年前の英文の再出題 1題 ＋ 新規 1題」**。再出題までの間隔は中央値 5.00年（`analysis/01_出題周期と焼き直し分析_2N.md`）。
- つまり **過去約5〜6年分の英文を訳せるようにしておくことが、1題分の得点に直結する**。もう1題は初見英文なので、下の解読手順で部分点を取りにいく。

## 2. 解読アルゴリズム（初見英文用）

| STEP | やること | 試験での処理 |
|---|---|---|
| 1 | **見出しを読む** | 見出し（例: Survival Craft / Regulation 15 ...）でテーマが決まる。答案の最初の名詞はほぼこれ |
| 2 | **助動詞に印を付ける**: shall / must / should / may / is to / is required to | ここが文の「結論」。shall・must →「〜しなければならない」、should →「〜すべきである」、may →「〜してもよい／〜することがある」 |
| 3 | **助動詞の左＝主語**、**右＝動詞** | 主語は長くても「〜は」で切る。動詞の後ろが be＋過去分詞なら受け身（STEP7） |
| 4 | **専門用語を拾って日本語に置き換える** | 下の語句表。ここが部分点の中心 |
| 5 | **that / which / where / who 以下は「かたまり」で囲む** | 名詞の後ろの which/that/who/where は、その名詞の説明として前に回す（「〜する（ところの）○○」） |
| 6 | **of / for / with / by / in / on 句は後回し** | まず「主語＋助動詞＋動詞＋目的語」を訳し、前置詞句は最後に付け足す |
| 7 | **be ＋ 過去分詞 は「〜される」** | shall be provided →「備えられなければならない」、should be maintained →「維持されるべきである」 |
| 8 | **when / if / unless / before / after / while の節は文頭に置く** | 「〜の場合は、」「〜でない限り、」「〜の前に、」「〜の間、」で始めて主文につなぐ |
| 9 | **箇条書き（.1 .2 / (a)(b)）は番号ごとに独立して訳す** | 前文の「〜shall:」が全項目にかかる。各項目の頭にその動詞を補う |
| 10 | **日本語として並べ替える** | 「（条件）、（主語）は、（前置詞句）（目的語）を（動詞）しなければならない。」 |

## 3. 構文 → 日本語の処理表

| 英語の形 | 答案での処理 |
|---|---|
| A shall 動詞 | Aは〜しなければならない |
| A shall be 過去分詞 | Aは〜されなければならない |
| A shall not 動詞 | Aは〜してはならない |
| A must 動詞 / must be 過去分詞 | Aは〜しなければならない / 〜されなければならない |
| A should 動詞 / should be 過去分詞 | Aは〜すべきである / 〜されるべきである |
| A may 動詞 | Aは〜してもよい（文脈により「〜することがある」） |
| A is required to 動詞 | Aは〜することが要求される |
| A is responsible for 名詞/〜ing | Aは〜に責任を負う |
| A is used for / to 動詞 | Aは〜のために使用される |
| ensure that 文 | 〜であることを確保する（確実にする） |
| in order to 動詞 | 〜するために |
| so that 文 | 〜するように |
| so as to 動詞 | 〜するように |
| such as A, B | A、B などの |
| as far as practicable / where practicable | 実行可能な限り |
| unless otherwise 過去分詞 | 別段の〜がない限り |
| in accordance with A | Aに従って |
| with regard to / in respect of A | Aに関して |
| A as well as B | BだけでなくAも／A及びB |
| not only A but also B | AだけでなくBも |
| take into account / take into consideration A | Aを考慮に入れる |
| at all times | 常に |
| it is essential / important that 文 | 〜することが不可欠である／重要である |

## 4. 部分点答案の3段階（作り方）

1. **満点答案**: STEP1〜10を全部やる。
2. **英語が苦手でも書ける答案**: STEP1・2・3・4・7・10 だけ。前置詞句と関係詞節は省略してよい。
3. **最低限の部分点答案**: 「見出しの日本語」＋「主語」＋「助動詞の日本語」＋「拾えた専門用語」を1文にする。

例（説明用の作例。過去問ではない）:
> The master shall ensure that the intended voyage has been planned using appropriate nautical charts and nautical publications.

- 拾えた語: master / shall ensure / voyage / planned / nautical charts
- ③最低限: 「船長は、航海が海図を使用して計画されたことを確保しなければならない。」
- ②苦手でも: 「船長は、予定された航海が適切な海図及び水路図誌を使用して計画されていることを確保しなければならない。」

**白紙にしない**。主語と shall の訳だけでも、文の骨格が合っていれば部分点の対象になり得る（採点基準は非公開のため、どの程度加点されるかは不明）。
